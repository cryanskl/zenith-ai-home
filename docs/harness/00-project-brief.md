# Project Brief

## 项目定位

`zenith-ai-home` 是一个中文 AI 个人品牌 landing page，面向技术同行。它不是普通简历页，也不是资讯站，而是一个展示 AI 工程实践、项目证据、关键经历和技术判断的个人主页。

访问者应该在一分钟内理解：

- 你关注哪些 AI 工程问题
- 你做过哪些 AI 项目或实验
- 你的关键经历、活动、人物连接和外部认可是什么
- 你如何使用 prompt、工具和工程方法解决问题
- 你有哪些技术见解值得继续阅读

## V1 范围

V1 只做单页 landing page。

包含：

- Hero 与个人定位
- AI 项目展示
- 关键经历 Timeline
- 推荐提示词
- 技术见解入口
- 推荐阅读
- 联系方式

不包含：

- CMS
- 多页面博客系统
- 搜索
- 每日热点自动刷新
- 后台管理
- 登录、评论、订阅、数据库
- 自动抓取外部资讯

## 页面顺序

1. Hero
2. Featured AI Projects
3. Timeline
4. Recommended Prompts
5. Technical Insights
6. Recommended Reading
7. Contact / Footer

## 成功标准

- 技术同行能快速判断这是一个 AI 工程实践者的主页。
- 项目、Timeline、Prompt、文章、阅读推荐各自职责清楚。
- 页面看起来专业、克制、可阅读，而不是通用 AI 模板。
- 所有真实经历和成果都等待用户提供，不由 agent 编造。
